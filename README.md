# Noctelle

Aplikasi pencatatan dan ringkasan tidur berbasis Flutter.

## Menjalankan aplikasi

Ambil dependensi terlebih dahulu:

```powershell
flutter pub get
```

Jalankan versi web di Chrome:

```powershell
flutter run -d chrome
```

Jalankan di emulator atau perangkat Android yang terhubung:

```powershell
flutter devices
flutter run
```

Noctelle menampilkan splash screen animasi singkat sebelum membuka beranda.

## Menjalankan tes

```powershell
flutter test
```
