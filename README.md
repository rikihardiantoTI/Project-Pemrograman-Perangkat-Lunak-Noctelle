# Noctelle

Aplikasi pencatatan dan ringkasan tidur berbasis Flutter.

Fitur utama:
- Ringkasan skor dan progres target durasi tidur yang dapat disesuaikan.
- Catatan sesi tidur, riwayat dengan filter skor, dan grafik mingguan.
- Pengaturan waktu tidur dan preferensi pengingat.

## Menjalankan aplikasi

Ambil dependensi terlebih dahulu:

```powershell
flutter pub get
```

Jalankan versi web di Chrome:

```powershell
flutter run -d chrome
```

Jalankan di emulator atau perangkat Android yang terhubung:

```powershell
flutter devices
flutter run
```

Noctelle menampilkan splash screen animasi singkat sebelum membuka beranda.

## Menjalankan tes

```powershell
flutter test
```
